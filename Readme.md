# Python for AI

## Overview
This repository contains Python projects that demonstrate programming skills used in artificial intelligence, data analysis, and machine learning workflows.

## Skills
- Python programming
- Data processing
- File handling
- Text processing
- Data analysis
- Problem solving

## Projects

### 1. Data Cleaning
Reads a CSV file, removes missing values, and prepares data for analysis.

### 2. Text Processing
Processes text by counting words, removing punctuation, and converting text to lowercase.

### 3. JSON Parser
Loads and extracts information from JSON files.

### 4. CSV Analysis
Analyzes tabular data and calculates basic statistics.

### 5. File Automation
Automates repetitive tasks such as renaming and organizing files.

## Tools
- Python 3
- CSV
- JSON
- Pandas

## Goal
Build practical Python skills for AI training, data annotation, machine learning, and data science.
